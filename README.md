# Aulas · Daniel Marques

Página inicial e sites interativos das aulas, prontos para o GitHub Pages.

Cada tema é um site independente na sua pasta (ver o README dentro de `clc6/` para editar slides, questionários e pesquisas).

## Como aceder a cada aula?

O site fica em `https://<o-teu-utilizador>.github.io/aulas/`. Cada tema tem o seu endereço, por exemplo `…/aulas/clc6/`.

## Acrescentar um tema ou uma disciplina

1. Colocar a pasta do site do tema dentro da pasta da disciplina (por exemplo `ai-2ano/o-trabalho/`).
2. Em `catalogo.js`, acrescentar ou completar a linha do tema com `pasta: 'ai-2ano/o-trabalho/'`.

Um tema sem `pasta` aparece na página inicial como «Em preparação».

Usa só letras minúsculas, números e hífenes nos nomes das pastas (sem espaços nem acentos).
